# Pamiętniczek Pakera – strony www

Publiczne strony aplikacji Pamiętniczek Pakera (iPhone), wymagane przez App Store.
Kod aplikacji jest w osobnym, prywatnym repozytorium.

- `index.html` – pomoc i kontakt (adres „Support URL” w App Store Connect)
- `polityka-prywatnosci.html` – polityka prywatności (adres „Privacy Policy URL” i link w aplikacji)

Strony serwuje GitHub Pages z gałęzi `main` (folder główny):
- https://maku-dev191.github.io/pamietniczek-pakera/
- https://maku-dev191.github.io/pamietniczek-pakera/polityka-prywatnosci.html
